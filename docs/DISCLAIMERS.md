## AI outputs can be wrong

AEGIS composes large-language-model agents with on-chain data via the OnchainOS CLI. Both can
fail. Sources of failure include:

- The CLI returns stale, incomplete, or geo-blocked data.
- An agent misinterprets an ambiguous instruction.
- A token's on-chain field is adversarially crafted to manipulate downstream agents (we
  defend against this in `skills/_shared/prompt-injection.md`, but no defence is perfect).
- Market conditions change between scan and broadcast.

## Volatility and total loss

Crypto markets are extremely volatile. Strategies can lose 100 % of capital. AEGIS is designed
to **reduce** but not **eliminate** that risk. The kill switch (`aegis-hibernator`) is sticky
for exactly this reason: if the framework can't make a safe decision, it should not act.
